# 品牌资源

`internal-asset-library-logo.png` 是“云汀素材管理工具”的当前正式标志原图，由项目方提供。`internal-asset-library-logo.svg` 仅作为引用该原图的兼容入口，不再维护另一套独立图形。

桌面客户端 `Assets` 目录中的多尺寸 PNG 和 `internal-asset-library.ico` 均由上述 PNG 原图生成，是同一品牌资源的构建副本，不是独立来源的美术素材。
